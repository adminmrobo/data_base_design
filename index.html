“표를 어떻게 나눠 담아야, 틀리지 않고 빨리 꺼낼 수 있을까?”

교안(PDF)과 노션 강의 페이지를 바탕으로, 박사·조수 하루·초파리 연구원·주판봇이 한 회차씩 진행하는 해설 페이지입니다. 회차마다 직접 눌러 보는 실험, 페이지 안에서 바로 실행되는 SQL 실습실, 확인 퀴즈, 대결, 지식 색인이 들어 있습니다. SQL 실습은 강의 노션의 실습 페이지를 그대로 따라가고, 같은 예제를 이 페이지에서도 실행해 볼 수 있습니다.

박사

한 주에 한 문, 열다섯 개의 문을 지난다. 8번과 15번 문은 복습실이다.

조수(하루)

저는 1번 문부터 차례로 갈게요. 각 페이지 끝의 퀴즈로 제가 어디까지 왔는지 확인할 수 있어요.

강좌 안내

데이터베이스의 개념을 이해하고 구조·설계 등 다양한 특징을 배웁니다. 이를 근거로 설계에 필요한 모델을 익히고, 데이터베이스 도구(MariaDB 등)를 직접 실습합니다.

1개념과 구조데이터베이스의 개념과 특징, 데이터베이스 구조를 배웁니다.
2설계데이터베이스 설계를 배우고, 실습으로 체계적으로 익힙니다.
3명령어 활용데이터베이스 활용을 위한 명령어(SQL)를 씁니다.

15회차

초록 카드는 리뷰 회차입니다. 각 회차는 따로 읽어도 되도록 만들었고, 페이지 맨 위 “30초 복습”이 앞 회차를 이어 줍니다.

01주차과목 사용 설명서편의점 계산대에서 출발해, 엑셀과 DB의 차이·실습 도구·15주 지도를 한 번에
02주차데이터와 데이터베이스데이터와 정보의 차이, 데이터베이스의 정의(공유·통합·저장·운영)와 특징, 데이터의 분류
03주차데이터베이스 관리 시스템파일 시스템의 중복·종속·회복 문제, DBMS의 정의·세 기능·장단점, 1~4세대 발전사
04주차데이터베이스 시스템DB 시스템의 구성, 외부·개념·내부 스키마, 논리적·물리적 독립성과 사상, 데이터 사전, 사용자·언어·DBMS 구성
05주차데이터 모델링과 E-R 모델현실 세계→컴퓨터 세계의 추상화, 요구사항 문장 분석, 개체·속성(단순·복합·다중값·유도·키), 관계와 1:1·1:N·N:M
06주차관계 데이터 모델릴레이션·속성·튜플·도메인·차수·카디널리티, 릴레이션의 네 특징, 슈퍼키·후보키·기본키·대체키·외래키, 개체·참조 무결성
07주차관계 데이터 연산관계 대수의 8가지 연산, 셀렉트·프로젝트, 합·교·차·카티션 곱, 조인(동등·자연·외부·세미), 디비전 — 노션 JOIN 실습
08주차 · REVIEW중간 REVIEW데이터·DBMS·3단계 스키마·E-R 모델·관계 모델·관계 연산을 지도·낱말 카드·SQL 종합 실습·모의 문제 20개로 복습
09주차SQL ① 데이터 정의SQL의 분류(DDL·DML·DCL·TCL), CREATE TABLE의 다섯 부분, NOT NULL·DEFAULT·PRIMARY KEY·UNIQUE·FOREIGN KEY·CHECK, ON DELETE 옵션, ALTER·DROP·TRUNCATE
10주차SQL ② 데이터 조작과 조인SELECT(조건·LIKE·NULL·정렬), 집계 함수와 GROUP BY·HAVING, 조인과 부속 질의, INSERT·UPDATE·DELETE, 뷰와 삽입 SQL — 노션 market 데이터로
11주차데이터베이스 설계 5단계요구 사항 분석 → 개념적 설계(E-R) → 논리적 설계(변환 규칙 5) → 물리적 설계 → 구현, 한빛 마트 사례와 RPG 실무 사례
12주차정규화삽입·갱신·삭제 이상, 함수 종속(완전·부분·이행), 1NF·2NF·3NF·BCNF와 4·5NF 개요, 무손실 분해, 반정규화와 실무 판단
13주차트랜잭션 · 회복 · 병행 제어트랜잭션과 ACID, COMMIT·ROLLBACK(노션 TCL·DCL), 로그 기반 회복(REDO·UNDO·검사 시점), 갱신 분실과 로킹·2단계 로킹, 교착 상태
14주차데이터베이스 응용 기술비정형 데이터와 빅데이터 3V, 4세대 이후 DBMS(NoSQL·NewSQL), 문서형 데이터베이스(MongoDB)와 해시태그 사례, 색인으로 빨라지는 조회(RPG 사례), 운영용 DB와 분석용 DB
15주차 · REVIEW기말 REVIEWSQL(DDL·DML)·설계 5단계와 변환 규칙·정규화·트랜잭션과 회복·병행 제어·응용 기술을 지도·낱말 카드·종합 SQL 실습·모의 문제 20개로 복습
